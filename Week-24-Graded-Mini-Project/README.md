# Week 24 Graded Mini Project: Grounded Answers from a Small Knowledge Pack

IITM Pravartak - Professional Certificate Programme in Generative AI and Machine Learning

This is a lightweight RAG pipeline (LangChain + FAISS + Gemini) over 7 HR policy PDFs of a **fictional** company, Kestrel Data Labs. The experiments compare:
- chunking (300 / 600 / 1000 characters, 10-20% overlap)
- OpenAI vs open-source embeddings
- two citation-enforcing prompts (P1 concise, P2 Evidence → Answer)

Every configuration runs with `ConversationBufferMemory` across 3-turn conversations.

## Files

| File | Purpose |
|---|---|
| `Week 24_Graded Mini Project_Jain.ipynb` | Main notebook: Tasks 1-8 end to end |
| `rag.py` | The pipeline: loader, splitter, embeddings, FAISS, LCEL chain, prompts P1/P2, memory session |

| `outputs/` | Charts and result tables |
| `cache/` | Cached LLM responses and embeddings, so re-runs are free and identical |

## How to run

You need Python 3.12.

**1. Install the packages:**

```bash
python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

**2. Add your API keys.** Copy `.env.example` to `.env` and fill in the two keys:
- `GOOGLE_API_KEY` for Gemini (the free tier is enough)
- `OPENAI_API_KEY`, used only for `text-embedding-3-small`

`.env.example` also fixes the model used for these results: `GEMINI_MODEL=gemini-3.5-flash-lite`.

**3. Run the notebook:**

```bash
.venv/bin/python make_corpus.py
.venv/bin/jupyter nbconvert --to notebook --execute --inplace "Week 24_Graded Mini Project_Jain.ipynb"
```

The submitted `logs/` and `cache/` already hold all 70 answers. A re-run therefore reproduces the same results without calling Gemini. Only the embedding speed measurement (section 4b) calls OpenAI, for a fraction of a cent. To call the APIs again from scratch, delete `logs/run_log.*` and `cache/`.

**Manual evaluation (Task 7):** `logs/manual_scores.csv` holds the rubric score for every answer. Each score was drafted by `scoring.py` and then reviewed by hand (`reviewed = True` on all 70 rows). The notebook reads this file for the summary tables.

## Reproducibility

- **Fixed settings:** seed 42, `top_k = 4`, and exact FAISS search. The LLM is `gemini-3.5-flash-lite`, which is the code default and set in `.env.example`. `gemini-2.5-flash` is retired for new keys, and `gemini-3.8-flash` was overloaded at run time. Temperature 0 is requested, but this model uses fixed sampling and ignores it, so exact reproducibility comes from the response cache. Gemini 3 models reason briefly before answering; those hidden tokens are logged separately and excluded from the answer-length check.
- **Deterministic inputs:** the corpus is regenerated by `make_corpus.py`, and package versions are pinned in `requirements.txt`.
- **Caching:** LLM responses and embeddings are cached on disk, so re-running gives identical answers without API calls. To call the APIs again, delete `cache/` and `logs/run_log.*`.
